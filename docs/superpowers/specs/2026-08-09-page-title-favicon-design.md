# 网页标题与品牌图标设计

## 目标

把开发代号 `dark-song-01` 替换为适合展示和交付的产品标题，并移除仍在使用的 Vite 默认 favicon。

## 方案

- 浏览器标题：`声音植物园｜声音驱动的 3D 表型实验台`
- favicon：使用 64 × 64 的轻量 SVG；深绿圆角底板承接页面背景，薄荷绿交叉轨道对应页头 `brand-orbit`，三个发光节点对应声音特征、基因型和表型之间的转换。
- 保留 SVG 单色轮廓在小尺寸下的辨识度，不加入文字、渐变滤镜或外部字体。
- 同步把根文档语言从 `en` 改为 `zh-CN`，并补充中文页面描述元数据。

## 范围

只修改 `index.html` 与 `public/favicon.svg`，不调整 React 页面、路由、构建配置或运行时依赖。

## 验证

- 自动测试读取真实入口文件，断言正式标题、中文语言、描述和 favicon 引用。
- 生产构建通过。
- 浏览器加载后检查标题、favicon 请求和控制台状态。
